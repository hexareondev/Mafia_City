# ♠ Мафия — онлайн-игра для компании

Классическая «Мафия» для 4–16 игроков. Полностью статический проект:
без сервера, без баз данных, без регистрации. Подключение по коду комнаты
через WebRTC (PeerJS) — браузер создателя игры выполняет роль хоста.

## Запуск
- Локально: просто откройте `index.html` (или `npx serve`).
- GitHub Pages: положите файлы в репозиторий → Settings → Pages → Deploy from branch. Готово.

## Как играть
1. Один игрок нажимает **«Создать игру»** и делится кодом из 4 символов (или ссылкой).
2. Остальные вводят имя и код — попадают в лобби.
3. Хост настраивает роли/таймеры и начинает партию: роли раздаются, ночь сменяет день.

### Механики
- Роли: Мафия, Дон, Шериф, Доктор, Мирные жители (баланс под размер компании).
- Ночь: мафия убивает, шериф проверяет (дон скрыт от проверки), доктор лечит
  (нельзя лечить одного дважды подряд), первая ночь — знакомство мафии.
- День: обсуждение в чате по таймеру → голосование (большинство, при равенстве — никто не изгнан).
- Мёртвые наблюдают и общаются в «чате мёртвых», не мешая живым.
- Победа: мафия истреблена → город победил; мафии ≥ мирных → мафия победила.
- После финала хост может пересдать роли в той же комнате.

## Архитектура
- Один файл `index.html`, сеть — [PeerJS](https://peerjs.com) (публичный signaling-сервер, ключи не нужны).
- Хост-авторитарная модель: вся логика и состояние в браузере хоста, клиенты получают персональные срезы данных.

## Ограничения (честно)
- Хост должен оставаться онлайн; если он закроет вкладку, комната закроется.
- Нет реконнекта после обрыва связи.
- В очень строгих корпоративных сетях WebRTC может не пробиться (нужен TURN-сервер).

## Идеи для развития
Голосовой чат, роль Маньяка/Путаны, кик игроков, миграция хоста, статистика партий.
